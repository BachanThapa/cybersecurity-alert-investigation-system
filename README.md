# cybersecurity-alert-investigation-system
A demonstration Multi-Agent AI System designed to assist cybersecurity teams in investigating simulated security alerts and assessing potential threats.

Project Overview
This project explores how multiple AI agents can collaborate to analyse security events, evaluate potential risks and generate investigation reports.

AI Agents
The workflow consists of five specialised agents:
Evidence Correlator
Context & Behaviour Analyst
Risk & Severity Assessor
Evidence Sufficiency Guardrail
Escalation & Reporting Agent

Key Features
Security alert investigation
Suspicious activity analysis
Threat severity assessment
Evidence validation
Automated investigation reporting
Human-in-the-loop review

Technologies Used
n8n
GPT-4.1 Nano
OpenRouter
AI Agents
Workflow Automation

Project Background
Developed as part of the PAIR: Pexus AI Readiness Program conducted by Pexus Tech.

Project Purpose
To demonstrate how Multi-Agent AI systems can support cybersecurity analysts in investigating security alerts while keeping final decisions under human control.
